# Care Dental Clinic — 20 SEO Guide Pages

This package contains the supplied homepage as `index.html` plus 20 detailed guide pages.

## Publication notes
- The homepage design system, theme colours, typography, navigation language and footer structure were preserved from the supplied source.
- Each guide has unique SEO metadata, H1/H2 structure, content, FAQs, CTA copy and a distinct placeholder visual URL.
- Placeholder visuals are intentionally labelled in the pages. Replace them with images you own or have a licence to publish before production.
- No treatment price has been invented where the supplied homepage did not publish a topic-specific price.
- Clinical language is written as educational content and avoids promising outcomes for every patient.
- The local pages use “best dentist” as the target search phrase but explain that “best” is not an objective universal ranking.
